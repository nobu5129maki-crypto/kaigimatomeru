# 会議まとめ

録音や文字起こしを、選んだ長さと書き方でまとめ、パソコンで清書できるファイルにします。

まとめの計算はこの端末の中だけで行います。会議の文章をサーバーへ送りません。録音の文字起こしだけは、ブラウザの音声認識を使います。

## できること

- その場で録音して文字にする（Chrome など、音声認識に対応したブラウザ）
- 文字の貼り付け、`.txt` `.md` `.vtt` `.srt` の読み込み
- 100文字、200文字、400文字、800文字、A4用紙一枚
- 読みやすいメモ、新聞記事、政治記者風、議事録、社内連絡
- Word（.docx）、テキスト、Markdown で保存。対応端末では共有シートからパソコンへ送れる
- ホーム画面に追加してアプリのように開ける

音声ファイルそのものの自動文字起こしには対応していません。

## 開発

```bash
npm install
npm test
npm run dev
npm run build
```
