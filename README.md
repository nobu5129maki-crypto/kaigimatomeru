# 会議まとめ

録音や文字起こしを、選んだ長さと書き方でまとめ、パソコンで清書できるファイルにします。

まとめの計算、録音、文字起こしはこの端末の中だけです。初回だけ、文字起こし用のモデルを受け取ります。会議の音声はサーバーへ送りません。

## できること

- その場で高音質の音声を録音し、話しながら文字起こし欄へ出す。一時停止、音量、音声ファイルの保存ができる
- 文字の貼り付け、`.txt` `.md` `.vtt` `.srt` の読み込み
- 100文字、200文字、400文字、800文字、A4用紙一枚、2,000文字、4,000文字
- 見出し、箇条書き、結論先出し、時系列、速報、5W1H、報告書、新聞記事、政治記者風、議事録、社内連絡
- 相手の話が長いときは「要は、何が言いたい？」で、言いたいことだけを箇条書きにする
- Word（.docx）、テキスト、Markdown で保存。対応端末では共有シートからパソコンへ送れる
- ホーム画面に追加してアプリのように開ける

音声ファイルそのものの自動文字起こしには対応していません。

## 開発

```bash
npm install
npm test
npm run dev
npm run build
```
